# Автотесты сайта

- `tropinki.test.mjs` — проверяет «Генератор тропинок в снегу»: мои поля, все узоры (отскоки, кольца,
  круглые во всех режимах, pattern.monster, картинка), способы (пешком/снегоступы/лыжи/лопата), трассу, экспорт.
  Внешние сервисы отключены — проверяется только код сайта. Каждый маршрут проверяется: точки внутри поля,
  длина нормальная, в подсказках нет «undefined», «NaN» и двойных точек.
- `live-services.mjs` — проверяет, что отвечают карта AR5 (NIBIO), кадастр (Kartverket), OpenStreetMap, Nominatim, Leaflet.

GitHub запускает всё сам (`.github/workflows/tests.yml`) после каждого изменения в `tropinki/` и каждое воскресенье.
Результат — вкладка **Actions** в репозитории; при ошибке GitHub присылает письмо.

Запуск у себя: `cd tests && npm install && npx playwright install chromium && npm test`
