# Генератор тропинок в снегу

Страница: https://esstariolai.github.io/tropinki/

Выбираешь поле на карте (контуры из OpenStreetMap через Overpass API) или задаёшь размеры,
генерируешь узор и проходишь его по пошаговому навигатору — пешком или на лыжах.
Все повороты привязаны к бортам, воротам или к уже протоптанным следам.

Узоры раздела «pattern.monster» взяты из проекта Pattern Monster
(https://github.com/catchspider2002/svelte-svg-patterns), лицензия MIT — см. LICENSE-pattern-monster.md.
